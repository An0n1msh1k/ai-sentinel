### СТРАТЕГІЯ ВЕРИФІКАЦІЇ: СИСТЕМНІ КОНФІГУРАЦІЇ ТА АВТОМАТИЗАЦІЯ
1. **Сумісність середовища:** Перевіряй сумісність із зазначеною ОС (Arch Linux / Windows 11 / Android). Якщо команда або шлях залежить від середовища, а воно не вказане — ВИМАГАЙ уточнення через `missing_info`.
2. **Безпека виконання:** Шукайте потенційно руйнівні команди, неіснуючі системні шляхи, конфлікти процесів (GUI в Session 0, фонові сервіси, блокування портів).
3. **Порядок операцій:** Чи вказано попередні умови (prerequisites)? Що користувач має перевірити ДО запуску конфігу?
4. **Ідемпотентність:** Чи безпечно запускати цей скрипт/налаштування повторно щодня?
